# Page Types

## Core Types

| Type | Job | Primary patterns |
|---|---|---|
| Home | Establish identity and site direction. | Editorial hero, current update, track split, latest list. |
| About | Explain person, values, and background. | Narrative sections, timeline, profile facts, quote. |
| Academic / Research | Make research agenda and publications credible and scannable. | Sticky side rail, publication list, filters, metadata rows. |
| Practice / Work | Show applied work across classroom, product, tools, writing, and resources. | Audience taxonomy, format list, featured items, tool/resource modules. |
| Writing Index | Help readers scan writing by topic, series, and recency. | Filter bar, featured row, list, horizontal series rail. |
| Article Detail | Provide a calm reading experience with content-led concept anchors. | Reading column, article header, pull quote, code panel, figure block, callouts chosen from the article text. |
| Lab Note / Experimental Content | Support technical experiments and tool logs without retro-computer styling. | Code panels, steps, screenshots, annotations, dense notes. |
| Tool / App | Support repeated functional use. | Sticky header, tabs, controls, cards, forms, modal details. |
| Resource / Tutorial | Teach a process or package reusable material. | Sticky side nav, steps, code, comparisons, checklist, accordion. |
| Project / Publication Detail | Explain a specific case, study, or output. | Split intro, method blocks, timeline, result cards, detail table. |
| Event / Landing | Create occasional campaign rhythm and action. | Stronger hero, agenda, proof, CTA, FAQ. |
| Social / Article Cards | Turn ideas into shareable card sets. | 3:4 or 16:9 exportable card layouts. |

## Rules

- Choose the page type before choosing components.
- Do not force every page into a landing-page rhythm.
- Do not force article components before reading the article. Cards, quotations, callouts, paths, figures, and motion must come from the content's actual structure.
- Do not reuse Portfolio's old article style.
- Do not use Portfolio content unless the user explicitly provides it or asks for a Portfolio-specific design.

## Final Page Decisions

- Home baseline: Dual Track Home when the site needs equal Academic / Practice entrances. Include current update / recent activity as a real content block.
- Article baseline: content-led reading page. The design system supplies possible components, but article text decides what appears.
- Tool / Resource baseline: denser and more functional than homepage surfaces; use controls, tabs, filters, lists, and calm cards.
- Dot Grammar / Symbol System is not a standalone Portfolio homepage page type. It is design-language support for interaction, diagrams, and figures.
