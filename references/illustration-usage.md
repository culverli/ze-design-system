# Illustration And Symbol Usage

## Ze Character

Use Ze only when Ze performs a meaningful conceptual action. Ze should not be decoration.

For strict character generation or QA, use the `ze-universe-ip` skill and its approved visual anchors.

For article illustrations, use the `ze-article-illustrations` skill.

## Article Figures

Use 16:9 figures for:

- A core argument.
- A process breakpoint.
- A before/after contrast.
- A reusable system.
- A failure mode.
- A decision path.

Each figure should explain one small concept.

## Abstract Symbols

Allowed symbols:

- Dot: focus, pause, continuation, possibility.
- Circle: question, openness, attention.
- Square: structure, system, product.
- Triangle: growth, teaching, direction.
- Path: movement, journey, transformation.
- Nodes: relationships and concept networks.
- Infinity: long-term continuity.

Rules:

- Symbols are grammar, not characters.
- Do not add faces, limbs, emotions, or companion roles.
- Use symbols in UI interactions, section markers, diagrams, and figure annotations.

## Cursor And Interaction

Dot can be used for:

- Cursor enhancement.
- Focus point.
- Active nav marker.
- Loading rhythm.
- Section marker.

Dot must remain abstract and non-personified.
