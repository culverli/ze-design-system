# Brand DNA

## One Line

Calm but not flat. Minimal but not empty. Hand-drawn but not childish. Low-saturation color supports hierarchy, highlights, states, and local meaning.

## Final Baseline

The final Ze Web baseline is white-first, low-saturation, editorial, Ze Rough Line-aware, and motion-aware. It is a reusable design-system direction, not a Portfolio-only redesign.

The baseline keeps:

- White canvas.
- Neutral ink.
- Local low-saturation color.
- Ze Rough Line modes for hand-drawn borders, dividers, paths, frames, and selected controls.
- Dot / symbol grammar for interface states.
- Content-led article composition.
- Dual-track homepage structure when the page needs Academic / Practice parity.

The baseline rejects:

- Portfolio's old gray-green as a system color.
- The old retro-computer article style.
- Dot Grammar as Portfolio homepage content.
- Generic card-grid landing pages as the default structure.

## Identity

Ze Design System is a reusable web design language for Zehao Li's personal IP, writing, research, tools, and future websites. It is not Portfolio-specific.

It inherits Ze Universe principles:

- Ze is the only character.
- States are expressions of Ze, not separate characters.
- Dot and abstract symbols are grammar, not companions.
- The primary mark is `Ze.` when a readable mark appears.

For Portfolio-like pages, Dot Grammar supports the interface language only: cursor, focus, hover, loading, section marker, or transition states. It should not become homepage content or replace the person's own identity, research, practice, and current work.

## Visual Tone

Use:

- Pure white as the default canvas.
- Near-white surfaces only for local grouping, never as a gray-green page atmosphere.
- Black, graphite, gray, and low-saturation accents.
- Notion-like text colors, highlights, and tinted backgrounds.
- Fine editorial structure.
- Excalidraw / Rough.js-style line qualities where they add human texture.
- Richness from page taxonomy, components, interaction, motion, and concept illustrations.

Avoid:

- The old Portfolio gray-green as a system color.
- The old retro-computer/window-like Portfolio article style.
- Bright gradients, neon, glassmorphism, glossy UI, heavy shadows, and stock-photo atmospheres.
- Cute mascot behavior, childish sticker styling, or multiple Ze-like characters.
- Cards everywhere as the default page structure.
- Repeated AI-looking scaffolds such as identical feature-card grids, decorative gradient text, and tiny uppercase labels above every section.

## Color Philosophy

Color is allowed, but it should be low-saturation and local. It can mark:

- Headings and subheadings.
- Tags and filters.
- Callouts and highlights.
- States and feedback.
- Flows, paths, warnings, and secondary notes.
- Page sections that need gentle distinction.

Color does not need to explain something every time, but it should never feel decorative for its own sake.

The default color strategy is **restrained**: neutral canvas and ink carry most of the page; low-saturation color appears in local highlights, labels, callouts, paths, and state changes.

## Line Philosophy

Use Ze Rough Line as the confirmed hand-drawn material:

- **`rough-hairline`:** subtle structural borders, frames, and quiet separators.
- **`rough-pencil`:** more visible dividers, underlines, callout separators, and article annotation paths.
- **`rough-strong`:** selected controls, CTAs, and product/tool modules. Use sparingly.
- **`rough-path`:** Dot paths, conceptual flows, article figures, and relation diagrams.

Never make the interface feel like rigid corporate SaaS.

The line should feel like Excalidraw / Rough.js adapted to Ze: double-pass stroke, small coordinate drift, mild bowing, occasional variable weight, clean white space, and no messy childish doodle. Read `references/line-language.md` before generating or judging line work.

## Motion Philosophy

Motion clarifies focus, state, and hierarchy. Ze motion can include Dot cursor, hover lift, line draw, section reveal, list rhythm, tab transitions, accordion transitions, and loading dots. Avoid spectacle, bounce, elastic easing, and infinite decorative motion.

## Character Use

Ze may appear in web pages, but only when Ze helps communicate:

- Research.
- Building.
- Teaching.
- Long-term thinking.
- A concrete conceptual action.

Do not place Ze only to decorate a page.

Abstract symbols follow the same rule: use them when they clarify interaction or structure, not when the page needs actual personal or project content.
